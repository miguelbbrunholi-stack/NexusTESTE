# Deploy NexusFinance on Vercel

This repository is prepared as a monorepo deployment:

- `NexusFinance/` -> Expo Router web app, exported to `NexusFinance/dist`.
- `backend/` -> FastAPI application exposed through `api/index.py`.
- `/api/v1/*` -> FastAPI routes on the same Vercel domain.

## Vercel project settings

Use the repository root (`ProjetoNexus`) as the **Root Directory**.
The committed `vercel.json` supplies the build and output settings.

Do not upload or commit `backend/.env`. Configure production values in Vercel Environment Variables.

Required production variables:

- `DATABASE_URL` - MySQL connection string, using a cloud-accessible database.
- `ENVIRONMENT=production`
- `CORS_ORIGINS` - JSON list if you later serve the frontend from another origin.
- `STORAGE_DIR=/tmp/nexus-storage` (temporary runtime storage only).
- `SESSION_DAYS`
- SMTP variables if password recovery by email is enabled.

For the web frontend, `EXPO_PUBLIC_API_URL` is optional when frontend and API share the same Vercel project: the app automatically uses `/api/v1` on the current origin. If the API is deployed separately, set `EXPO_PUBLIC_API_URL` to that API's public base URL.

## Important

Vercel Functions have a writable `/tmp` filesystem, but it is temporary. Files uploaded/generated by the backend should not be treated as permanent storage. Use persistent object storage if the application needs durable files.
